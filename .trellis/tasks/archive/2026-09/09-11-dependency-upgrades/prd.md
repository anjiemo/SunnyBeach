# 按优先级升级项目依赖

## 目标与范围

核查版本目录、Gradle Wrapper、构建插件和 CI Action 的已发布版本，按优先级升级至兼容稳定版。

## 升级顺序

1. P0：Gradle、AGP、Kotlin、KSP、Hilt、AndroidAOP 和构建插件。
2. P1：AndroidX、Compose、网络、序列化、存储和图片/媒体库。
3. P2：第三方 UI、工具和厂商 SDK。
4. P3：测试、调试依赖和 CI Action。

## 约束

- 以实际仓库元数据为依据，不猜测版本，不降级现有依赖。
- 默认稳定版；现有预发布依赖单独核查。
- 保持 minSdk、应用版本和业务行为；必要时修复升级引起的兼容问题。
- 保留原文件末尾换行状态及用户未提交文件。
- 不执行包含生产 API 写操作的开发者测试脚本。
- 不发布、不推送远程分支。

## 验收

- [x] 完成所有声明依赖的版本核查，记录不能升级的原因。
- [x] 完成可兼容升级及必要适配。
- [x] 运行 Debug 构建和 Lint，记录结果或环境阻碍。
- [x] 审查差异及换行状态，按项目提交规范提交。

## 结果

升级 15 个版本目录项、Gradle Wrapper 和 5 类 CI Action，共 21 项。Debug 构建成功，Lint 为 0 errors / 399 warnings，actionlint 1.7.12 检查通过。保留没有更新稳定版的依赖和无法自动追溯的本地 `.so`，详见 `research.md`。
